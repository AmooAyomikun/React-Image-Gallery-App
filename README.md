# Lens - Image Discovery Gallery

A modern image discovery platform built with React that allows users to search, explore, save, and organize high-quality images from Unsplash through a responsive and interactive user experience.

---

## Live Demo

Live Site: (https://amooayomikun.github.io/React-Image-Gallery-App/)

---

## Project Overview

Lens is a responsive image gallery application that enables users to search millions of high-quality images through the Unsplash API.

The application was built to strengthen my understanding of:

- API integration
- Infinite scrolling
- State management
- Local storage persistence
- Responsive UI development
- Component-based architecture
- Modern React development

Users can search for images, browse detailed image information, save favorites, switch between different viewing modes, and build a personal collection of liked images.

---

## Features

### Image Search

Search millions of images using the Unsplash API.

- Instant image discovery
- Dynamic search results
- Optimized API requests

---

### Infinite Scrolling

Additional images load automatically as users scroll.

Benefits:

- Better user experience
- Reduced pagination friction
- Continuous content exploration

---

### Category Filtering

Refine search results using predefined categories.

Examples:

- Nature
- Architecture
- Travel
- People

---

### Orientation Filtering

Filter images by:

- Landscape
- Portrait
- Square

---

### Grid and List View Modes

Users can switch between:

#### Grid View

Optimized for browsing many images.

#### List View

Optimized for viewing larger image previews and details.

---

### Image Details Modal

Clicking an image opens a detailed preview modal.

Available information includes:

- Photographer name
- Description
- Likes
- Downloads
- Views
- Tags

---

### Favorites System

Users can save favorite images.

Features:

- One-click saving
- Persistent storage
- Dedicated favorites panel

---

### Local Storage Persistence

Saved images remain available even after:

- Refreshing the page
- Closing the browser
- Returning later

No authentication required.

---

### Responsive Design

The application adapts to:

- Desktop
- Tablet
- Mobile devices

Responsive layouts were implemented using:

- CSS Grid
- Flexbox
- Media Queries

---

### Lazy Loading

Images load only when needed.

Benefits:

- Faster initial page load
- Reduced bandwidth usage
- Improved performance
